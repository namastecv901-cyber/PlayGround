📐 طريقة الشراء على النموذج — لا شراء قبل اكتمال كل الشروط — شراء فقط
  1. 1) انتظار الكسر: النموذج لا يُفعّل إلا بإغلاق شمعة فوق مستوى الاختراق (خط الرقبة/المقاومة). اللمس أو الشمعة الجارية لا يكفي.
  2. 2) تأكيد الكسر: حجم شمعة الكسر ≥1.5× متوسط 20 شمعة + إغلاق واضح فوق المستوى + EMA20>EMA50 + السعر فوق EMA20 + درجة ≥75 + RR≥1.5. الكسر الضعيف أو الوهمي يُلغى.
  3. 3) الدخول: مباشر بعد إغلاق شمعة الكسر، أو آمن عند إعادة الاختبار للمستوى وارتداده لأعلى. لا تشترِ إذا كان السعر >1.2% فوق المستوى.
  4. 4) الوقف: تحت مستوى الكسر (وقف فشل الاختراق). إغلاق شمعة تحت المستوى = فشل الكسر → خروج.
  5. 5) الأهداف: هدف1/2/3 من ارتفاع النموذج وATR. أغلق جزءاً عند هدف1 وارفع الوقف للتعادل بعده.
  6. 6) الإلغاء والخروج: عودة الإغلاق داخل النموذج، كسر وهمي، حجم ضعيف، أو اتجاه هابط. لا مطاردة، لا شراء قبل الكسر، شراء فقط بلا شورت.

  2. الفريمات: 1H للفرص المتوسطة • 4H للنماذج الأقوى • 1D للاتجاه الكبير. نستخدم الشموع المغلقة فقط (نستبعد الشمعة الجارية) لمنع إعادة الرسم.
  3. مستوى التأكيد: خط الرقبة أو المقاومة/سقف النمط. الشرط هو إغلاق شمعة فوقه، وليس لمسه. الاختراق الوهمي (عودة الإغلاق داخل النمط) يُلغي الإشارة.
  4. الحجم: الشراء الذهبي يتطلب حجم شمعة الاختراق ≥1.5× متوسط 20 شمعة، والمراقبة/المعلّق ≥1.0×. الحجم الضعيف يخفض الدرجة ويمنع إشارة الشراء.
  5. الاتجاه: EMA20 > EMA50 والسعر فوقهما يزيد الجودة. النمط الانعكاسي ضد هبوط قوي يُرفض أو يُخفَّض.
  6. الوقف: أسفل مستوى الاختراق بمسافة = الأكبر بين 1×ATR أو 1% من السعر (وقف فشل الاختراق)، وليس أسفل قاع النمط البعيد. هذا يقلل المخاطرة ويرفع RR، لكنه قد يُضرب عند إعادة اختبار عميقة — لذلك الدخول عند المستوى أفضل من مطاردة السعر.
  7. الأهداف: هدف1 = مستوى الاختراق + ارتفاع النمط (أو 1.5×ATR) • هدف2 = 1.7×الارتفاع • هدف3 = 2.4×الارتفاع، مع حد أدنى من ATR. تُحسب RR بعد رسوم 0.2% وتُرفض الإشارة إذا RR < الحد المختار.
  8. مراحل الشراء: 👀 يتشكل ← ⏳ مراقبة حتى يكتمل الكسر والحجم والاتجاه ← 🟡 شراء ذهبي مكتمل فقط عندما يكون السعر 0.2%–1.2% فوق المستوى وتكتمل كل الشروط. لا شراء أخضر ولا شراء قبل الاكتمال.
  9. الرفض: سعر ممتد >8% فوق المستوى • RR <1.5 • مخاطرة وقف >12% • حجم <1.5× • اتجاه غير مكتمل • درجة <75. البطاقات غير المكتملة تُراقب ولا تظهر كشراء.
